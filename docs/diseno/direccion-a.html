#Arquitectura General
El sistema MyDamnManagement almacena toda la verdad en ficheros .md con frontmatter YAML en el disco local, mientras mantiene un índice en SQLite para búsquedas rápidas (FTS5) y vistas relacionales.
##Principios de Diseño
La base de datos nunca es la fuente primaria; si el índice se borra, el vault reconstruye todo el estado en segundos. Incluso las filas de bases de datos viven como documentos Markdown individuales.
Consulta también Guía de Despliegue y Hoja de Ruta Q4 para ver cómo encaja con el resto del proyecto.
