Tokens de captura

Un token de captura solo sirve para crear notas en la bandeja (POST /capture). Los usan los atajos de macOS, Windows y Linux (ver tools/capture/).

Este es el token, y no se vuelve a enseñar. Cópialo ahora y guárdalo en el atajo (MDM_TOKEN). Si lo pierdes, revócalo y crea otro.

Un nombre solo sirve para reconocer la llave en esta lista.
