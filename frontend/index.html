Plantillas de fila

El «+ Nueva fila» de esta base ofrecerá estas plantillas: nombre, valores por defecto y, si lo hay, el cuerpo con el que nace la fila. Se guardan en el fichero de la base.

Nueva vista

Filtrar «»

Se enseñan las filas que cumplen todas las condiciones (Y). El filtro es de esta vista: las demás pestañas no lo heredan.

Ordenar «»

Manda la primera clave; las siguientes desempatan. Las filas sin valor van al final en las dos direcciones.

Procesar «»

La nota pasa a colgar de la página elegida (que hace de carpeta) y se abre. Si escribes un nombre nuevo, se crea ahí.

Tokens de captura

Un token de captura solo sirve para crear notas en la bandeja (POST /capture). Los usan los atajos de macOS, Windows y Linux (ver tools/capture/).

Este es el token, y no se vuelve a enseñar. Cópialo ahora y guárdalo en el atajo (MDM_TOKEN). Si lo pierdes, revócalo y crea otro.

Un nombre solo sirve para reconocer la llave en esta lista.

Cambiar contraseña

Al menos 8 caracteres. Al cambiarla se cierran las demás sesiones abiertas.
